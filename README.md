# MoodDay

Aplicação para registro emocional diário.

## Funcionalidades

- Registro de Humor
- Histórico semanal
- Filtro de emoção
- Dashboard gráfico
- Exportação PDF
- Editar registros
- Excluir registros

## Tecnologias

HTML, CSS, JavaScript, Chart.js, jsPDF, LocalStorage.
